# Frontend folder

This is the original teammate's mobile-first HTML/CSS/JavaScript UI, integrated with the FastAPI API and IndexedDB outbox.

Do not launch it with VS Code Live Server for the full-stack prototype. Start the FastAPI host from the project root with:

```powershell
.\scripts\start.ps1
```

Then open `http://127.0.0.1:8000`. Full setup and test instructions are in the root `README.md` and `docs/DEMO_GUIDE_BN.md`.
